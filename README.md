# 🏛️ JEE Main 2026 — Modern Concept Redesign

> **An Awwwards-tier, student-first concept redesign for India's largest engineering entrance examination.**  
> Built from a raw paper sketch with AI & modern frontend engineering.

🌐 **Live Demo:** [https://jee-main-redesign.vercel.app](https://jee-main-redesign.vercel.app)  
📺 **YouTube Case Study:** [@srijanpandeydev](https://www.youtube.com/@srijanpandeydev)

---

## ✨ Key Features
- **Visual Student Journey**: Playful hand-drawn stick figure animations showing students searching for exam centres.
- **1-Click Action Cards**: Direct, unconfusing access to Candidate Login, City Allotment Slip, and Admit Card downloads.
- **Interactive Tools**: Dynamic JEE Score Calculator, Rank Predictor, and College Matrix Slider with real-time feedback.
- **Tactile Blueprint Aesthetic**: Subtle engineering graph paper grid, dark slate backdrop, and crisp modern typography.
- **100% Mobile Responsive**: Thumb-friendly touch navigation with zero horizontal overflow.

---

## 🛠️ Tech Stack
- **HTML5 / CSS3 / Vanilla JavaScript** (Zero bloated runtime dependencies)
- **Fluid Layouts & CSS Grid / Flexbox**
- **Public Sans & JetBrains Mono Typography**
- **Vercel Global Edge Network Deployment**
